# SCRMS — Supply Chain Risk Monitoring System

Operator dashboard for supply chain disruption monitoring and forecasting.

## Tech stack

- Vite + React + TypeScript
- shadcn/ui + Tailwind CSS
- TanStack Query + Recharts

## Development

```sh
npm install
npm run dev
```

The dev server runs on port 8080. The backend API is expected at port 8000 (see `src/lib/config.ts`).

## Build

```sh
npm run build
```
